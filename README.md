# Exposure Catalog

[Exposure](https://modrinth.com/mod/exposure) addon that adds an entity catalog
that can be filled with the camera.

## Filling the Catalog

By default, the catalog can be opened by pressing `o`. To fill catalog entries, you just need to take a photo
of one (or multiple!) entities using Exposure's camera.

Catalog Entries are data-driven, meaning modpacks can define new entries easily.

## Supported Versions

- Fabric - 1.20.1

I may port this to multiloader at some point if i have the time/motivation, but as of writing
its just a small fabric mod. If anyone else wanted to port it tho feel free!
